# Plan — 공유 유입 점검과 오류 복구

## 목표

공유 링크의 정상·삭제·조회 실패 흐름을 검증하고 운영 차단 원인을 기록한다

## 작업 범위

1. 공유 구현·운영 응답을 대조한다.
2. 삭제 콘텐츠는 기본 카드와 홈으로 이동. 조회 장애는 원래 목적지 보존.
3. 기사 딥링크 실패 안내·재시도, 탐색 후 늦은 응답 무시.
4. 백엔드 회귀, 프런트 테스트/빌드, 격리 Playwright 공유 흐름 검증.
5. 운영 차단·실카드·성과 측정의 미검증 항목을 남긴다.

## 검증 계획

- 실행할 명령은 프로젝트 설정을 확인한 뒤 `verify`로 기록한다.
- 실행하지 못한 항목은 통과가 아니라 미검증으로 남긴다.
- 필수 검증: 별도 선언 없음

## 위험

- 아직 기록된 위험 없음
